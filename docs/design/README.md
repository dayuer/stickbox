# Handoff: StickBox · Claude 用量看板（1080p 电视版）

## 概述
在 1920×1080 电视上显示 Claude 订阅的两个用量窗口（5 小时 / 7 天），让房间里任何位置一眼看出额度够不够用；右上角是翻页时钟。数据由电脑每 10 分钟 `POST /api/usage` 上报。

## 关于设计文件
`design/` 里的 HTML 是**设计参考**（展示外观与行为的原型），不是可直接上线的代码。请在目标环境（Web/React、Electron、Android TV、LVGL 等）里按现有模式重新实现。文件可离线直接用浏览器打开。

- `StickBox TV（离线）.html` — 电视版，可交互：时钟走动、倒计时每秒刷新
- `设计说明（离线）.html` — 设计文稿（含截图，可打印成 PDF）
- `StickBox 240屏（离线）.html` — 早期 240×240 设备屏方案与状态全集（参考）
- `screenshots/` — 电视版 5 种状态截图（安全 / 超速 / 危险 / 用满 / 无数据）

## 保真度
**高保真**。颜色、字体、尺寸为最终值；按 1920×1080 画布绘制，整体等比缩放适配屏幕（`scale = min(vw/1920, vh/1080)`，黑边居中）。

## 状态与颜色
每个窗口独立判定；环、大数字、预测同色。

| 状态 | 条件 | 色值 | 结论句 |
|---|---|---|---|
| 安全 | 能撑到重置，或 t < 5% | `#3DDC84` | 两个窗口都够用 |
| 超速 | 预计用完时间 < 剩余时间 | `#FFB020` | {窗口}额度用得偏快 |
| 危险 | 超速且 u ≥ 0.9 | `#FF5A5A` | {窗口}额度快用完了 |
| 用满 | u ≥ 1 | `#FF5A5A` | {窗口}额度已用满 |
| 无数据 / 已重置 | 未收到上报 / 已过 resets_at | `#7A7A7D`，数字 `--` | 等待电脑上报数据 |

结论句：安全或无数据时为 `#F5F5F8`，其它为状态色。

**主次自动**：状态等级 用满 4 > 危险 3 > 超速 2 > 安全 1 > 无数据 0；高者居主位；同级比 `u ÷ t`，大者居主位。

## 计算
输入：每窗口 `used_percentage`（u，0–1）与 `resets_at`（Unix 秒）；窗口长 W = 5h / 7d。
- rem = resets_at − now；t = 1 − rem / W
- 预计用完时间 = (1 − u) ÷ (u ÷ (W − rem))
- 节奏 = round((u − t) × 100)
- 建议上限 = (1 − u) ÷ (rem / 86400) ×100 %/天（7 天）；÷ (rem / 3600) %/时（5 小时）；用满显示 `--`
- 时间格式：≥1 天 `X天Y时`；≥1 小时 `X时YY分`（不足 1 天的剩余时间加 `YY秒`）；否则 `X分YY秒`
- 每秒刷新倒计时与「更新 X分前」；超过 15 分钟未更新时底栏左侧变 `#FFB020`
- 无数据时底栏左：`尚未收到上报 · {IP}`，右：`POST /api/usage`

## 状态变量
- `now`（每秒 tick）、`windows[5h|7d] = { u, resetsAt } | null`、`lastUpdate`、`deviceIp`
- 派生：每窗口 t / rem / 状态 / 预测；主次分配；结论句
