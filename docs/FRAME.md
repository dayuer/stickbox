# 帧接口约定（T13a ↔ T13b）

状态：**草案，待 T13b 确认**。第 3 节的版面冲突必须先定，渲染器的时钟部分才能定稿。

本文约定服务端（T13a）交给设备（T13b）的**底帧 + 元数据 + 字形掩码**，
以及设备用 `rom/main/jband.h` 做每分钟时钟局部重编码时的输入条件。
帧分发端点、MQTT 通知、flash 分区布局不在本文范围（见 T9/T13b）。

---

## 1. jband 的硬约束

`rom/main/jband.h` / `jband.c` 是设备侧唯一的重编码入口，它要求：

| 约束 | 值 / 说明 |
|---|---|
| 编码格式 | baseline、8 位、YCbCr 4:2:0、两张量化表、标准 4 张哈夫曼表 |
| MCU | 16×16；1920×1080 → **120 列 × 68 行** |
| 重启间隔 | **DRI = 每行 MCU 数 = 120**；每行末尾一个 RSTn（最后一行不补） |
| 行边界 | `jb_parse` 用 RSTn 切出 `row_off[r]`；段间 DC 预测清零 |
| 重编码范围 | `jb_encode_rows(p, r0, r1, bg, fg, shade, ctx, box, out, cap)` 只能按**整行**替换 |
| 颜色 | 只有 `bg` / `fg` 两种 RGB888；框外所有像素一律填 `bg` |
| 着色器 | 每个与 `box` 相交的 MCU 调 16×16 次 `shade(x,y,ctx)`；返回 true = fg |
| box | 矩形 `{x0,y0,x1,y1}`，**右/下开区间**；着色器在 box 外必须返回 false |
| 行数上限 | `JB_MAX_ROWS = 68`，正好等于 1080/16 向上取整 |

**结论：设备替换的是整条 MCU 横带，不是时钟那个小矩形。** 横带内、
`box` 外的像素会在输出流里变成纯 `bg`。这条约束决定了下面的版面冲突。

## 2. 时钟区

- 时钟所在 MCU 行：**r0 = 3，r1 = 17**（y 48..272，14 行）
- 时钟图形范围（设计稿）：x 1222..1848，y 48..270
- 数字卡片：132×184；两张一组、组内间距 6；冒号区宽 48
- 四张卡片左上角 x：1241 / 1379 / 1559 / 1697，y = 67

底帧里这 14 行**整行留空**：填 `bg`（`#1D2D3D`），不画网格、不画标题、
不画时钟。设备每次只重编码这 14 行，再按 `row_off[3]` / `row_off[17]` 拼回。

> 1080 不能被 16 整除，最后一行（r=67）底部 8px 是编码填充；
> 底帧与设备编码共用同一张量化/哈夫曼表，填充不影响拼接。

## 3. 版面冲突（必须先确认）

设计稿的时钟横带（y 48..272）里**不只是时钟**：

| 内容 | 位置 | 是否在时钟行内 |
|---|---|---|
| 小标 `CLAUDE 用量 · 10月17日 周六` | x 72.., y 64..90 | 是 |
| 结论句（76px） | x 72.., y 104..约185 | 是 |
| 翻页时钟 | x 1222..1848, y 48..270 | 是 |
| 主/次面板 | y ≥ 290 | 否 |

设备整行重编码时，框外一律填 `bg`。如果 `box` 只覆盖时钟，
**小标和结论句会被擦掉**。当前版面里也找不到一条 14 行高、且不含其它内容的空带
（上方面板从 y 290 开始，标题占 64..185）。

三个可选方案，请 T13b / USB-TV 定一个：

### 方案 A：整条状态带做掩码（保留现有版面与翻页时钟）

- `box` 扩到整条带：`[0, 48, 1920, 272]`
- 元数据除数字掩码外，再带一张**静态带掩码**（小标 + 结论句 + 时钟边框/卡片/冒号）
- 两种颜色：`bg = #1D2D3D`，`fg = 结论句颜色`（安全/无数据为 `#F5F5F8`，
  超速 `#FFB020`，危险/用满 `#FF5A5A`）
- 数字是卡片上的**洞**：`fg = static(x,y) && !digit(x,y)`
- 代价：设备要解码/查询一张 1920×224 的 1-bit 掩码；小标与卡片会跟随状态色；
  文字是 1-bit（无抗锯齿）
- 好处：版面、翻页时钟外观、结论句位置都不变

### 方案 B：时钟缩成顶部时间条（设备最简单）

- 放弃 132×184 翻页卡片，改为 `HH:MM`（Barlow 700，约 28px）放在
  **r0 = 4，r1 = 6**（y 64..96），x 约 1700..1830
- 小标上移到 y 32..58（r2..r3），结论句仍在 y 104 起（r6 之后），互不重叠
- `box` 只覆盖时间条，设备只需 0–9 与冒号的掩码
- 代价：翻页时钟的视觉标志丢失（但仍不做翻页动画）

### 方案 C：重排版面

为 14 行空带腾位置，需要把结论句/面板整体下移或缩小主环。
改动大，需要重新出设计稿；不建议在 T13a/T13b 里临时做。

**建议**：优先 A（保设计），若 T13b 认为 1-bit 全带掩码在 ESP32 上代价过高，
退 B。**确认前 T13a 不提交时钟的最终实现**；当前 `render-preview` 里的彩色时钟
只用于对照设计稿。

## 4. 底帧

- 1920×1080 baseline JPEG，4:2:0，**DRI=120，每行末尾 RSTn**
- 第 2 节那 14 行整行填 `bg`，其余区域按设计稿正常渲染
- 时钟横带内不画网格线（否则设备重编码后与底帧不一致）
- 目标 ≤120KB，硬上限 128KB（设备 flash 每槽 128KB）
- 底帧与元数据一起下发；元数据里带底帧的 SHA-256

> Go 标准库 `image/jpeg` **不写 DRI/RST**。T13a 需要自带一个支持重启间隔的
> baseline 编码器（或给标准库补这一小段），这是 T13a 的实现前提。

## 5. 元数据

JSON，UTF-8，独立于传输方式（HTTPS 响应体或与帧一起打包）。字段：

```json
{
  "v": 1,
  "width": 1920,
  "height": 1080,
  "frame_sha256": "<64 hex>",
  "jpeg": { "dri": 120, "mcu_cols": 120, "mcu_rows": 68 },
  "clock": {
    "rows": [3, 17],
    "box": [0, 48, 1920, 272],
    "bg": "#1D2D3D",
    "fg": "#F5F5F8",
    "static_mask": {
      "x": 0, "y": 48, "w": 1920, "h": 224,
      "encoding": "rle-spans-u16",
      "data": "<base64>"
    },
    "slots": [
      {"x": 1241, "y": 67, "w": 132, "h": 184},
      {"x": 1379, "y": 67, "w": 132, "h": 184},
      {"x": 1559, "y": 67, "w": 132, "h": 184},
      {"x": 1697, "y": 67, "w": 132, "h": 184}
    ],
    "glyphs": {
      "0": {"ox": 0, "oy": 0, "w": 132, "h": 184, "encoding": "rle-spans-u16", "data": "<base64>"},
      "...": {},
      "9": {}
    },
    "glyph_mode": "hole"
  }
}
```

- `rows` 是 `[r0, r1)`；`box` 是 `[x0, y0, x1, y1)`，右/下开区间
- `slots` 固定四个，依次是小时十位、小时个位、分钟十位、分钟个位
- `fg` 取结论句颜色；设备重编码时把 `bg`/`fg` 原样传给 `jb_encode_rows`
- `frame_sha256` 覆盖底帧 JPEG 字节；元数据与帧必须同批下发

### 掩码编码 `rle-spans-u16`

按行存前景跨度，小端：

```
每行: u16 span_count
      重复 span_count 次: u16 x0, u16 x1   // 左闭右开，相对掩码 x
```

- `static_mask`：`x/y/w/h` 给出在整图中的位置；行优先，共 `h` 行
- 每个字形：`ox/oy` 是相对所在 slot 左上角的偏移；`w/h` 是字形掩码尺寸
- 位图只有 0/1，无 alpha；服务端用阈值 50% 把抗锯齿边缘压成 1-bit

设备合成一次分钟帧：

```
for each slot i:
    d = (i<2 ? hour : minute) 的对应十进制位
    digit[i] = glyphs[d] 平移到 slot[i]
fg(x,y) = static_mask(x,y) && !any_digit(x,y)
```

冒号点画在静态掩码里（不做闪烁）。

## 6. 偏差清单（相对 `docs/design/screenshots/`）

1. 时钟横带内没有网格线（整行被 `bg` 覆盖）
2. 方案 A：时钟卡片、边框、角标、小标使用结论句颜色，不再是白色/钢蓝
3. 方案 A：数字是 1-bit 洞，边缘无抗锯齿
4. 铰链保留为 `bg` 色横线（蓝），左右卡扣省略
5. 黑底翻页面板与 `#416180` 细边框在方案 A 中改为「状态色边框 + 页面底色」
6. 不做冒号闪烁、翻页动画（帧每分钟一换）
