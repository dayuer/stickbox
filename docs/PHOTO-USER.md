# 在电视上看自己的照片

StickBox 支持把照片放到电视上，和看板轮流播放。照片存在板子的 microSD 卡里，
**只上传一次**，之后每次播放都从卡里读，不占网络流量。

> 只有带 SD 卡槽的板子支持照片。没有卡槽的板子继续只显示看板，功能不受影响。

---

## 1. 准备一张卡

- 一张 microSD 卡（普通速度卡就够，容量 ≥1GB；200 张照片约 50MB）。
- **新卡，或者你愿意清空的旧卡。**
- 初始化会**清空整张卡**。这张卡之后是 StickBox 专用卡，不能直接插电脑当普通
  存储卡用；想恢复普通用途，需要先在电脑上重新格式化。
- 建议关机后再插卡，插好再上电。

## 2. 第一次使用：初始化

在电脑上（已安装并配对好 `stickbox-agent`）执行：

```sh
stickbox-agent photo init
```

会提示“会清空 SD 卡内所有数据”，输入 `yes` 确认。板子收到授权后会自动把卡
初始化好，大约几秒钟。授权只有 **10 分钟**有效，过期了就再执行一次。

如果卡之前被 StickBox 用过、但后来坏了（不是空白卡），普通初始化不会动它；
确实要清空时用：

```sh
stickbox-agent photo init --force
```

`--force` 会再确认一次。**卡完全读不了时任何命令都不会格式化它**，这是为了
避免误删；这种卡只能拿到电脑上重新格式化或换一张。

初始化完成后，用下面命令确认状态：

```sh
stickbox-agent photo ls
```

看到 `ready=true state=ok` 就说明卡准备好了。

## 3. 上传照片

```sh
stickbox-agent photo add 照片1.jpg 照片2.png 照片3.jpg
```

- 支持 JPEG 和 PNG。iPhone 的 HEIC 照片在 Mac 上会自动转成 JPEG 再上传。
- 上传后默认**自动加入播放清单**，马上就能在电视上看到。
- 只想存进卡里、暂时不播：

  ```sh
  stickbox-agent photo add --no-show 照片.jpg
  ```

- 想让它多停一会儿（默认 8 秒，可设 5–600 秒）：

  ```sh
  stickbox-agent photo add --secs 20 照片.jpg
  ```

服务端会自动处理照片：

- 缩放到 1920×1080，比例不符时加黑边，不裁切（不会切到人脸）。
- **剥掉照片里的位置、拍摄设备等全部信息**，原图不会保存在服务器上。
- 广色域照片的颜色可能略淡一点，这是为了统一颜色和隐私做的取舍。

## 4. 查看和删除

```sh
stickbox-agent photo ls
```

会列出每张照片的编号（前 8 位）、大小、停留时长、是否在播放清单里，以及
每台板子的卡状态（是否就绪、已缓存多少张、剩余空间、有没有坏图）。

删除：

```sh
stickbox-agent photo rm abcdef01
```

编号给前 8 位即可；如果有多张照片前缀相同，命令会提示你给更长的前缀。
删除后板子会在下一次同步时把那张照片从卡里回收，电视也不再播放它。

## 5. 电视上怎么播

- 看板和照片按清单轮流播放：**看板默认 20 秒，每张照片默认 8 秒**。
- 顺序按上传顺序；新增的照片排在最后。
- 照片是“纯显示”，不会叠加时钟或用量卡片。
- 电视只接受 **1080p** 的画面；4K 原图会被缩小到 1080p，清晰度以电视为准。
  竖拍照片会左右留黑边，不会被裁切。
- 同一账号下的多台带卡板子会各自下载、各自播放；没有卡的板子只播看板。

## 6. 容量和限制

| 项 | 限制 |
|---|---|
| 单张上传 | 20MB |
| 每人照片数 | 200 张 |
| 每人总大小 | 64MiB（缩放后） |
| 停留时长 | 5–600 秒 |

超过配额会直接拒绝上传，**不会自动删除旧照片**。需要先 `photo rm` 删掉一些。

同一张照片重复上传不会重复占空间。

## 7. 卡出问题时

- **没插卡 / 卡读不了 / 卡没初始化**：板子照常显示看板，电视不会黑屏；
  `photo ls` 会显示 `absent`、`uninit` 或 `fault`。
- **播放中拔卡**：板子不会重启，电视先回到看板；把卡插回去会自动恢复照片播放。
- **突然断电**：小概率会让卡对板子不可用。把卡拿到电脑上重新格式化（FAT 即可），
  再插回板子执行一次 `photo init`，然后重新上传照片。
- **某张照片坏了**：轮播会跳过它，其他照片和看板不受影响；`photo ls` 会显示
  “跳过”的编号。删掉后重新上传即可。

## 8. 隐私

- 原图只用于生成电视用的 1080p 版本，**服务器不保存原图**。
- 上传时会把位置信息、拍摄参数等元数据全部剥掉；下载到板子上的只有处理后的
  JPEG。
- 照片只属于你的账号；其他账号的设备拿不到你的照片。

---

有问题先跑：

```sh
stickbox-agent photo ls
stickbox-agent doctor
```

`photo ls` 能看出卡是否就绪、照片是否已经下载到板子；`doctor` 检查电脑端和
服务端的连接。
