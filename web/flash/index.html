FIRMWARE · USB SERIAL

插上板子，
点一下就能烧。

不用装 ESP-IDF，也不用命令行。桌面版 Chrome 或 Edge 打开本页，接上 USB，按下面三步走。

  1. 01

    插对 USB 口

    开发板上有两个 Type-C 时，插丝印为 USB 或 USB-OTG 的那个（原生 USB）；不要插标着 UART / COM 的口。

    StickBox PCB 的 USB-A 直接插电脑，不要插在电视上。线要能传数据，纯充电线不行。

  2. 02

    第一次烧录：按住 BOOT 再插

    按住板上的 BOOT 键不放，插上 USB，等页面里出现串口后再松开。

    已经烧过 StickBox 的板子通常直接插就能烧；找不到串口时再按上面的步骤来。如果还是找不到，拔掉重来，确认按的是 BOOT，不是 RST。

  3. 03

    烧完：配网 → 配对

    板子重启后会开一个热点 StickBox-Setup-XXXX，XXXX 是设备 MAC 的末四位。

    连上这个热点，浏览器通常会自动打开配网页；没弹出就访问 http://192.168.4.1，填家里的 Wi-Fi。

    配网后电视（或 LCD）会显示 6 位配对码，在电脑上运行 stickbox-agent pair <配对码> 就完成了。自托管的话，配网页里可以改服务器地址。
